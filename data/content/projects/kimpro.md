# Aimers — AI 인플루언서 마케팅 자동화 플랫폼

AI 멀티에이전트가 캠페인 기획부터 인플루언서 매칭·콘텐츠 가이드·계약 관리까지 전 과정을 자동화하는 인플루언서 마케팅 플랫폼.

## 프로젝트 개요

광고주가 인플루언서 마케팅 캠페인을 운영할 때 겪는 반복적인 작업(브리프 작성, 인플루언서 탐색, 아웃리치 가이드 생성 등)을 AI로 자동화하는 서비스입니다. LangGraph 기반 멀티에이전트 워크플로우가 캠페인 생성부터 가이드 생성까지의 단계를 이어서 처리하며, 각 단계에서 사용자와 실시간 스트리밍 채팅으로 상호작용합니다.

Turborepo 모노레포 위에 마이크로서비스를 나누고, 서비스 간 통신은 이벤트 드리븐 메시지 큐로 처리합니다. LLM 응답이 수 분씩 걸리는 특성상 HTTP 요청-응답으로는 커넥션 유지와 유실 문제를 감당할 수 없었기 때문에, 큐를 중심에 둔 구조를 선택했습니다. 게이트웨이가 API Gateway 역할을 하며 중앙 집중식 인증을 수행합니다.

공유 패키지에 타입·메시징 계약·데이터 접근 계층을 두어 각 앱은 로직을 연결하는 가벼운 통로로만 동작하게 했고, 경량 프레임워크 기반으로 빠른 응답 속도와 독립적 배포를 실현합니다.

## 기술 스택

- **프론트엔드**: Next.js 16 + React 19 + TypeScript + Tailwind CSS 4
- **백엔드**: Fastify 5 (TypeScript, ESM) 기반 마이크로서비스
- **AI/ML**: LangChain 1.2 + LangGraph 1.0 — 멀티 모델 구성
- **데이터베이스**: 문서 DB + 관계형 DB + 인메모리 저장소
- **메시징**: 매니지드 Pub/Sub (이벤트 드리븐 서비스 통신)
- **인프라**: Docker + Turborepo + Nginx + PM2 + 클라우드 매니지드 서비스

## 주요 기능

### AI 멀티에이전트 캠페인 자동화

Supervisor 에이전트가 사용자 의도를 파악하고, 영역별 전문 에이전트에게 작업을 위임합니다. 하나의 에이전트에 모든 도구를 넣었을 때 도구 선택 정확도가 급락하고 프롬프트가 서로 충돌하는 문제를 겪은 뒤, 실제 팀의 협업 구조를 본떠 역할을 나눈 결과입니다. 각 전문 에이전트는 자기 영역의 도구만 들고 있습니다.

### 이벤트 드리븐 마이크로서비스

실시간 채널이 사용자 메시지를 받으면 메시지 큐를 통해 에이전트 실행 서비스로 전달하고, 완료 이벤트는 알림·이력 워커가 비동기로 소비합니다. 서비스 간 직접 의존이 없어 독립적인 스케일링과 배포가 가능합니다. 워커가 재시작되어도 사용자 연결은 유지되고, 메시지는 큐에 버퍼링됩니다.

### 실시간 워크플로우 스트리밍

WebSocket으로 워크플로우 진행 상황을 실시간 전달합니다. 토큰 단위 텍스트, 도구 호출 시작·완료, 데이터 변경 — 세 층위를 나눠 전달해서, 3분짜리 작업도 사용자가 진행 상황을 계속 볼 수 있게 했습니다. 서브에이전트의 발화는 Supervisor가 종합해 한 목소리로 전달합니다.

### 작업 스냅샷 & 롤백

워크플로우 시작 시 데이터를 임시 저장소에 복사하고, 모든 변경을 거기에만 기록합니다. 정상 완료되면 DB에 한 번에 커밋하고, 실패하면 스냅샷만 폐기합니다. DB는 커밋 전까지 손대지 않으므로 "반쯤 수정된" 불완전한 상태가 영속되지 않습니다. 스냅샷에 실행 위치까지 담아 서버 재시작 후 중단 지점부터 재개할 수 있습니다.

### 미들웨어 파이프라인

프롬프트 지시는 모델이 무시할 수 있지만 미들웨어는 무시할 수 없습니다. 에이전트의 실행 단계를 가로채 동적 컨텍스트를 주입하고, 도구 에러에 성공·실패 구분을 부여하고, 서브에이전트를 생성합니다. Supervisor와 서브에이전트의 미들웨어 구성을 다르게 두어 역할에 따라 환경이 달라지도록 했습니다.

### Agent 평가와 Prompt Caching

프롬프트를 고칠 때마다 다른 시나리오가 망가지는 문제를 겪고, Task·Grader·Transcript 개념을 축으로 자동 평가 체계를 구축했습니다. 외부 의존성은 모킹하되 LLM과 도구 호출은 실제로 실행해, 추론 능력만 격리해서 측정합니다. 또한 시스템 프롬프트의 불변 부분과 가변 부분을 물리적으로 분리해 Prompt Caching 적중률을 유지하면서 동적 정보를 주입했습니다.

## 담당 영역

현장실습생/인턴으로 참여해 백엔드·AI 엔지니어링을 담당했습니다:

- **AI 에이전트 아키텍처**: Supervisor–서브에이전트 오케스트레이션 설계, LangGraph 워크플로우 그래프 구성, 미들웨어 파이프라인
- **마이크로서비스 설계**: 서비스 분리 전략, 이벤트 드리븐 통신, 게이트웨이 인증 흐름
- **실시간 채팅 시스템**: WebSocket 기반 워크플로우 스트리밍과 연결 라우팅
- **스냅샷 시스템**: 체크포인팅, 워크플로우 상태 영속화 및 롤백
- **모노레포 인프라**: Turborepo 빌드 파이프라인, 공유 패키지 설계, Docker 빌드 스크립트
- **환경 관리**: 시크릿 매니저 연동, 환경변수 동기화 CLI 도구
- **에이전트 품질**: 평가 체계 구축, 컨텍스트 엔지니어링, Prompt Caching 전략
