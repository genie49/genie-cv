# 보카톡톡 — 영어 단어 학습 플랫폼

학원용 영어 단어 학습 플랫폼으로, PHP/Vanilla JS 레거시 시스템을 Next.js 14로 전면 리빌드한 프로젝트입니다. EUC-KR 인코딩의 MySQL DB를 UTF-8로 마이그레이션하고, TTS 기반 발음 학습과 학습 데이터 보호, PWA 지원까지 구현하여 실제 학원에서 프로덕션 운영 중입니다. 약 1년간 1인 풀스택으로 설계·구현·배포·운영을 수행했습니다.

## 프로젝트 개요

기존 시스템은 PHP와 Vanilla JS로 구축되어 있었고, MySQL은 EUC-KR 인코딩으로 운영되고 있었습니다. 코드 유지보수가 어렵고, 모바일 대응이 불가능하며, 새로운 학습 기능 추가에 과도한 공수가 드는 상황이었습니다.

점진적 마이그레이션이 일반적으로 안전하다고 하지만, 이 경우엔 전면 재작성을 택했습니다. 비즈니스 로직이 뷰와 완전히 결합되어 재사용할 코드가 없었고, 진짜 자산은 코드가 아니라 10년치 데이터가 쌓인 DB였기 때문입니다. 1인 개발 환경에서 두 시스템을 병행 운영하는 것도 현실적이지 않았습니다. **코드는 전부 바꾸되 데이터는 한 바이트도 건드리지 않는다** — 이 원칙으로 DB 인코딩을 UTF-8로 전환하면서 기존 데이터를 무손실 마이그레이션했습니다.

## 기술 스택

- **프론트엔드**: Next.js 14, React 18, Tailwind CSS, Mantine 7, Framer Motion, Zustand, SWR
- **백엔드**: Next.js API Routes (Route Handlers), Prisma, MySQL (관리형 RDB)
- **AI/학습**: Cloud TTS, Vercel AI SDK, OpenAI
- **인프라**: Vercel, 오브젝트 스토리지, 서버리스 함수, Sentry, PWA
- **기타**: 실시간 통신 채널, 데이터 그리드, 차트, 엑셀 입출력

## 주요 기능

### 레거시 → Next.js 전면 리빌드

PHP/Vanilla JS 기반 시스템을 Next.js App Router로 완전히 재작성했습니다. 학습자용 앱과 관리자용 앱을 하나의 프로젝트 안에서 라우트 그룹으로 분리해, 코드와 배포를 공유하면서도 관심사는 나눴습니다. Prisma 인트로스펙션으로 레거시 스키마를 그대로 가져와 타입 안전성을 확보했고, 빌드마다 스키마와 클라이언트가 자동 동기화되도록 파이프라인을 구성했습니다.

### DB 마이그레이션 + EUC-KR → UTF-8 인코딩 전환

10년치 데이터의 인코딩을 전환했습니다. 단순한 캐릭터셋 변경이 아니라, 이중 인코딩된 데이터와 CP949·EUC-KR이 혼재된 데이터를 구분해 처리해야 했습니다. 바이트 패턴으로 인코딩을 감지하고 실패 시 폴백하는 변환 체인을 만들었고, 기관별로 흩어져 있던 테이블 구조도 함께 정규화했습니다. DB 전환은 일회성이지만 업로드 파일의 인코딩 처리는 상시 필요해, 런타임 감지·변환 로직도 함께 두었습니다.

### TTS 발음 학습 파이프라인

발음 합성 자체보다 **합성 결과를 어떻게 재사용할 것인가**가 과제였습니다. 브라우저 로컬 캐시 → 서버 측 오브젝트 캐시 → TTS API로 이어지는 3단계 캐싱을 구성해, 같은 발음을 두 번 합성하지 않도록 했습니다. 캐시 키를 데이터의 행 ID가 아니라 **실제 발음 텍스트 기준**으로 잡은 것이 히트율을 크게 끌어올린 결정이었습니다. 학습 시작 전 프리페치로 세션에 필요한 음성을 미리 받아, 학습 중 대기가 없도록 했습니다.

### 학습 데이터 보호

시험 중 정답이 응답에 노출되던 문제를, 정답을 숨기는 대신 **응답에서 아예 빼는 구조**로 해결했습니다. 클라이언트에는 문제와 섞인 선택지만 전달하고 판정은 서버에서만 수행합니다. 데이터 자산 유출은 별개 문제로 보고, 인증·전송 구간·응답 본문을 각각 다른 층에서 방어하도록 구성했습니다.

### 학원 관리 시스템

관리자 대시보드에서 학원·학생·학습 데이터·진도·통계·권한을 관리합니다. 학습 콘텐츠를 직접 생성·편집할 수 있고, 엑셀 대량 임포트와 기관 간 콘텐츠 공유를 지원합니다. 선생님이 여러 학생을 동시에 관리한다는 전제에서, 원시 데이터를 나열하는 대신 **다음 수업에 바로 반영할 수 있는 지표**로 정제해 보여주는 데 초점을 뒀습니다.

## 담당 영역

1인 풀스택으로 설계·구현·배포·운영 전체를 담당했습니다:

- **풀스택 개발**: Next.js App Router 기반 학습자 앱 + 관리자 앱 구현
- **DB 마이그레이션**: EUC-KR → UTF-8 인코딩 전환, 레거시 테이블 구조 정규화, ORM 도입
- **학습 도메인 구현**: 특허 알고리즘의 시스템 이식, 세션 상태 관리, 코칭용 통계 지표 설계
- **TTS 파이프라인**: 다단계 캐싱과 프리페치, 캐시 키 설계
- **인프라**: Vercel 배포, 관리형 DB·스토리지 연동, 에러 모니터링, PWA 설정
- **기간**: 2024.11 ~ 2025.10 (약 1년)
